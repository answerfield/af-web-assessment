# af-web-assessment

answerfield ist eine typisierte, deklarativ-reaktive Sprache für digitale Assessments. Dieses Repository enthält Angular-Komponenten und eine Web-App, die Testhefte aus fertigen Bundles durchführt.

## Pakete

| Paket | Inhalt |
|---|---|
| `@answerfield/angular` | Angular-Komponenten für Aufgaben und Testhefte |
| `@answerfield/assessment-web` | Web-App für Testhefte, mit einem Beispiel-Bundle |

Die Pakete liegen als Dateien an den [Releases](https://github.com/answerfield/af-web-assessment/releases).

## Bauen und testen

Voraussetzung ist Node.js 22.12 oder neuer.

```sh
npm ci && npm run build && npm test
```
